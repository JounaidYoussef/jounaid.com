# Jounaid.com 📄

Personal portfolio and blog built with **Astro**.

---

## 💻 Tech Stack

| Category               | Technology                                            |
| :--------------------- | :---------------------------------------------------- |
| **Main Framework**     | [Astro](https://astro.build/)                         |
| **Foundation**         | [AstroWind](https://github.com/onwidget/astrowind)    |
| **Type Checking**      | [TypeScript](https://www.typescriptlang.org/)         |
| **Styling**            | [TailwindCSS](https://tailwindcss.com/)               |
| **Package Management** | [pnpm](https://pnpm.io/)                              |
| **CI/CD**              | [GitHub Actions](https://github.com/features/actions) |
| **Deployment**         | [Netlify](https://www.netlify.com/)                   |
| **Code Quality**       | Prettier & ESLint                                     |

## 👨🏻‍💻 Local Setup

<!-- GETTING STARTED -->

### Prerequisites

- This project uses pnpm. If you don't have it installed:

  ```sh
  npm install --global pnpm
  ```

### Installation

1. Clone the repo

   ```sh
   git clone git@github.com:JounaidYoussef/Portfolio.git
   ```

2. Install packages

   ```sh
   pnpm install
   ```

3. Launch Project

   ```sh
   pnpm run dev
   ```

<!-- USAGE EXAMPLES -->

### Usage

the project will be running at `http://localhost:4321`
